# ReAct prompting

**ReAct** (short for "Reason + Act") is a prompting paradigm in which a large language model produces reasoning traces and task-specific actions in an interleaved sequence, rather than either thinking in isolation or acting without explanation.[^s1] It was introduced by Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan and Yuan Cao in a paper first posted to arXiv on 6 October 2022, whose third version is the ICLR 2023 camera-ready.[^s1] Yao and Cao described the work on the Google Research blog in November 2022, writing as members of the Brain Team.[^s2]

## How it works

A ReAct trajectory alternates three kinds of steps. A **thought** is free-form text that does not touch the environment; it only updates the model's context, for example by decomposing a goal into a plan, injecting commonsense knowledge, tracking progress or revising the plan after an exception.[^s2] An **action** is a text command executed by an external environment, such as a query to a simple Wikipedia API, and it returns an **observation** that is appended to the context before the next step.[^s1][^s2] For knowledge-heavy tasks the prompt alternates thought, action and observation densely; for long decision-making tasks with many actions, thoughts appear sparsely and the model itself decides when to reason.[^s2]

In the original work the method needed no training: a frozen PaLM-540B was prompted with a handful of hand-written example trajectories, one or two for the interactive tasks.[^s1][^s2] The authors also showed that successful trajectories generated by the prompted large model could be used to fine-tune smaller PaLM-8B and PaLM-62B models, reducing the need for human annotation.[^s2]

## Evidence

The paper reports results on four benchmarks. On the interactive environments ALFWorld (a text-based household simulator) and WebShop (online shopping), ReAct beat imitation-learning and reinforcement-learning baselines by an absolute 34 and 10 percentage points in success rate.[^s1] The Google blog gives the underlying figures: 71% success on ALFWorld versus 45% for an act-only prompt and 37% for imitation learning, and a WebShop score of 40 versus 30.1 for act-only.[^s2] On knowledge tasks the picture was mixed. With PaLM-540B, ReAct scored 27.4 exact match on HotpotQA (chain-of-thought: 29.4) and 60.9% accuracy on FEVER (chain-of-thought: 56.3%). The best results came from combining ReAct with chain-of-thought (35.1 and 64.6), still far below fine-tuned state of the art at the time (67.5 and 89.5).[^s2] The qualitative claim was that grounding in retrieved facts reduces hallucination and error propagation and makes trajectories easier for humans to inspect.[^s1]

## Limitations and critiques

ReAct inherits the brittleness of in-context prompting. The Google post shows an ALFWorld failure caused by a hallucinated thought, which a human fixed by editing two reasoning lines; the authors presented this editability as a feature for human-in-the-loop correction.[^s2] A 2024 preprint by Verma, Bhambri and Kambhampati questioned the paper's core explanation. In their experiments on sequential decision-making, interleaving thoughts with actions, and even the content of the thoughts, had little effect on performance. What mattered most was how closely the in-context examples resembled the query task, which they read as approximate retrieval rather than reasoning.[^s3] If that holds, ReAct prompts need instance-specific exemplars, which shifts work back onto the prompt designer.[^s3]

## In practice

ReAct's thought–action–observation loop became the default shape of LLM agents. Modern frameworks implement it with native function calling instead of parsing text actions. In LangGraph, `create_react_agent` builds a graph that calls tools in a loop until a stopping condition is met, routing to a tool node whenever the model's last message contains tool calls.[^s4] As of November 2026, the LangChain reference marks that helper as deprecated in favour of a newer `create_agent` function, a sign that the pattern is now treated as generic agent plumbing rather than a named technique.[^s4]

## Connections

ReAct **extends chain-of-thought**: it keeps the verbal reasoning trace but grounds it with actions, and the authors present the two as complementary.[^s1][^s2] It sits under **prompt engineering** and **tool use** as a broader category, and it **depends on few-shot prompting**, since the behaviour is induced by a few example trajectories.[^s1] It was **created** at Google Research (Brain Team) and **evaluated on** HotpotQA and ALFWorld, among others.[^s1][^s2] It is a basic building block of **AI agents** and **agentic workflows**, and is **implemented in** LangGraph.[^s4] It contrasts with **Toolformer**, which teaches tool calls through fine-tuning rather than prompting. Its main claimed benefit is reducing **hallucination** by grounding reasoning in retrieved facts.[^s1] Later agent methods such as **Reflexion** build on this loop and join the graph as related nodes.
